Images

  1. Загрузите картинку на Google Drive
  2. Нажмите правой кнопкой на файл → Share (Поделиться)
  3. В окне доступа выберите «Anyone with the link» (Все у кого есть ссылка)
  4. Нажмите «Copy link» (Копировать ссылку)
  5. Вставьте ссылку в поле ниже — она автоматически сконвертируется в прямой URL
  6. Нажмите «Apply» — картинка обновится в превью и в копируемом коде
Также работают любые прямые ссылки на картинки (не только Google Drive). Например: https://example.com/photo.jpg

Как использовать блок

Вставка в GetCourse

  1. Нажмите Копировать код на нужном блоке
  2. Откройте GetCourse → Сайт → ваша страница
  3. Нажмите Добавить блок → выберите HTML
  4. В редакторе нажмите кнопку </> (режим кода)
  5. Вставьте код Ctrl+V (или Cmd+V)
  6. Сохраните — блок появится на странице

Хотите изменить блок?

  1. Скопируйте код блока (кнопка Копировать код)
  2. Откройте claude.ai
  3. Вставьте код и напишите, что изменить. Примеры:
    • «Сделай картинку слева, а текст справа»
    • «Добавь третью колонку»
    • «Поменяй оранжевый цвет на синий»
    • «Увеличь шрифт заголовка»
    • «Сделай 4 карточки вместо 3»
  4. Скопируйте результат из Claude и вставьте в GetCourse

Советы

  • Каждый блок автономный — стили встроены прямо в код
  • Блоки адаптивны — выглядят хорошо на любом экране
  • Замените тексты, картинки и ссылки на свои
  • Цвета можно менять через переменные в начале <style>
